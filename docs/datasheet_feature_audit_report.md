# 데이터시트 기능 점검 보고서

점검일: 2026-05-31  
대상: `digikey_scraper/datasheet_viewer.py`

## 결론

자동화 가능한 범위에서는 데이터시트 기능 대부분이 정상 동작한다.  
전체 테스트, 정적 검사, OCR 진단, 합성 PDF 기반 UI/기능 점검은 통과했다.

초기 점검에서 사용자 입장에서 아래 2개는 문제로 확인됐고, 이후 개선을 적용했다.

1. 프리셋이 이미 선택된 상태에서 같은 프리셋을 다시 기대하면 필터가 재적용되지 않을 수 있음
2. AI 질문 컨텍스트가 현재 선택 영역에 강하게 묶여 있어, 핀맵을 선택한 상태에서 "최대 전압"을 물으면 전압 표가 컨텍스트에 충분히 들어오지 않을 수 있음

## 확인된 문제

### 문제 1. Balanced 프리셋 재적용 불명확

상태: 해결됨  
위치: `DatasheetViewer._on_preset_changed`

현상:
- 프리셋 콤보가 이미 `Balanced`인 상태에서 필터가 `Auto` 등 다른 값이면, 사용자가 `Balanced`를 다시 기대해도 currentIndex 변경 이벤트가 발생하지 않아 `original`로 복구되지 않을 수 있다.

사용자 영향:
- 프리셋과 실제 필터 상태가 다르게 보일 수 있다.
- "균형 프리셋인데 왜 자동/다른 필터가 적용되어 있지?"라는 혼란이 생길 수 있다.

개선안:
- 필터가 수동 변경되면 프리셋 상태를 `Custom`으로 바꾸기
- 또는 프리셋 버튼/메뉴 액션을 따로 두어 같은 프리셋도 강제 재적용 가능하게 만들기
- 프리셋 라벨 옆에 현재 적용 필터를 명확히 표시하기

적용:
- `Custom/사용자` 프리셋 추가
- 필터 수동 변경 시 프리셋을 `Custom`으로 전환
- 프리셋 선택 시 같은 필터여도 재적용 경로를 명확히 처리

### 문제 2. AI 질문 컨텍스트가 선택 영역에 과하게 의존

상태: 해결됨  
위치: `DatasheetViewer._build_datasheet_question_context`, `_question_terms`

현상:
- 핀맵을 선택한 상태에서 "최대 전압은?"이라고 질문하면, 선택 영역과 현재 페이지가 핀맵이므로 전압 표가 충분히 컨텍스트에 들어오지 않을 수 있다.
- 한국어 질문 토큰 `전압은` 같은 조사가 붙은 단어가 `전압` alias와 정확히 매칭되지 않을 수 있다.

사용자 영향:
- AI가 "모름" 또는 핀맵 중심 답변을 할 가능성이 있다.
- 사용자는 데이터시트 전체 질문을 기대하지만 실제로는 선택 영역 중심 질문처럼 동작할 수 있다.

개선안:
- 질문어 alias를 조사 제거/부분 매칭 방식으로 개선하기
- `최대`, `정격`, `전압`, `전류`, `온도` 등 한국어 키워드 확장
- 선택 영역이 있더라도 질문 키워드와 맞는 다른 페이지를 우선 검색해서 함께 넣기
- AI 질문 모드를 `선택 영역 기준` / `전체 데이터시트 기준`으로 분리하기

적용:
- 한국어 키워드 부분 매칭 추가
- `최대`, `정격`, `전원`, `입력`, `출력` alias 추가
- `선택`, `현재쪽`, `전체` AI 질문 범위 선택 UI 추가
- 전체 범위에서는 질문과 매칭되는 페이지를 우선 컨텍스트에 포함

## 사용자 관점 개선사항

1. 프리셋에 `Custom` 상태 추가
   - 필터를 직접 바꾸면 프리셋이 실제 상태와 어긋나지 않게 표시해야 한다.

2. AI 질문 범위 선택 UI 추가
   - `선택 영역`, `현재 페이지`, `전체 데이터시트` 중 선택할 수 있어야 한다.

3. 감지 후보 타입을 더 강하게 표시
   - 현재 후보명에 타입이 들어가지만, 색상/배지로 `전기특성`, `핀`, `패키지`, `오탐 가능`을 표시하면 더 명확하다.

4. 오탐 처리 후 복구 기능 추가
   - 현재 오탐은 즉시 제거된다.
   - 실수로 누른 경우 `되돌리기`가 필요하다.

5. 실제 제조사 PDF 벤치마크 추가
   - 합성 PDF 기준은 통과했다.
   - TI, ST, ADI, Infineon, Microchip 등 실제 PDF 5~10개에 정답 박스를 붙여 precision/recall/IoU를 측정해야 한다.

6. OCR 언어 선택 UI 추가
   - 내부 설정은 있으나 사용자가 UI에서 `eng`, `kor`, `eng+kor`를 바꾸기 어렵다.

7. 저장 후 사용자 피드백 강화
   - PDF/PNG/영역 저장 후 성공 메시지와 파일 위치 열기 버튼이 있으면 좋다.

8. AI 키 문제 메시지 세분화
   - 현재는 키 없음/준비 정도만 보인다.
   - 키 없음, 키 파일 읽기 실패, API 호출 실패, quota/rate limit을 구분하면 좋다.

9. 검색 실패 표시 개선
   - 검색어가 없을 때, 검색 결과가 없을 때, 검색은 됐지만 오버레이가 꺼져 있을 때를 구분해야 한다.

10. UI 실제 화면 점검 필요
   - offscreen 테스트는 기능 상태를 확인하지만 실제 DPI/창 크기/긴 한국어 라벨 줄바꿈은 눈으로 확인해야 한다.

11. 페이지 전체가 영역으로 저장되는 문제 방지
   - PDF 외곽 테두리나 큰 벡터 도형이 감지 후보로 들어오면 작은 표 후보를 병합 과정에서 덮을 수 있었다.
   - 페이지 면적/높이에 가까운 후보는 병합 전후로 제거하도록 수정했다.
   - 넓은 표는 유지하고, 페이지 전체에 가까운 영역만 제거하도록 조건을 조정했다.
